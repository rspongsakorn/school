# แก้การนำทางของรายงานการเงิน ข้อ 5–7

วันที่ 2026-11-26 · ขนาด: งานเล็ก · อนุมัติแล้วในบทสนทนา · งานต่อจาก `2026-11-26-finance-report-fixes-design.md`

## ที่มา

ตรวจผ่านเบราว์เซอร์บนฐานทดสอบ `school` แล้วยืนยันปัญหาสามข้อนี้

5. เมนู "รายงาน" ในแถบด้านข้างหุบอยู่ทั้งที่กำลังเปิดหน้ารายงาน เกิดเมื่อเข้าผ่าน `/reports` แล้วถูกส่งต่อไปหน้าค้างชำระ
6. ตัวกรองหายเมื่อกดย้อนกลับหรือรีเฟรช
   - หน้ารายรับรายวัน: วันที่กับรูปแบบเอกสารกลับเป็นค่าเริ่มต้น
   - หน้ารายบุคคล: คำค้นหาหายเมื่อเปิดดูนักเรียนแล้วกดกลับ และต้องรอโหลดใหม่ราว 14 วินาที
7. ในหน้าใบแจ้งยอดรายบุคคล ถ้าเปลี่ยนภาคเรียน ระบบพาออกไปหน้ารายชื่อ และหน้านี้ไม่มีปุ่มกลับไปหน้ารายชื่อ

## เป้าหมาย

- เมนูในแถบด้านข้างกางออกเองเมื่อหน้าที่เปิดอยู่เป็นของกลุ่มนั้น และผู้ใช้ยังกดหุบเองได้
- ตัวกรองต่อไปนี้อยู่ใน URL จึงอยู่รอดหลังกดย้อนกลับ รีเฟรช หรือคัดลอกลิงก์ไปเปิด
  - รายรับรายวัน: `from`, `to`, `method`, `doc`
  - ส่วนลด: `from`, `to`
  - สถิติ: `level`
  - รายบุคคล: `grade`, `classroom`, `status`, `q`
- เมื่อตัวกรองเป็นค่าเริ่มต้น ไม่ต้องใส่ลง URL
- หน้ารายบุคคลดึงข้อมูลใหม่เฉพาะเมื่อเปลี่ยนภาค ชั้น หรือห้อง ส่วนสถานะและคำค้นหากรองจากข้อมูลที่โหลดแล้ว
- หน้าใบแจ้งยอดรายบุคคล
  - เปลี่ยนภาคแล้วยังอยู่ที่นักเรียนคนเดิม
  - มีปุ่ม "← กลับไปรายชื่อ" ที่พากลับไปพร้อมตัวกรองเดิม

## ไม่ทำในรอบนี้

- ความเร็วในการโหลดครั้งแรก
- ลำดับเมนูและชื่อหน้า
- รูปแบบของช่องกรอกวันที่
- บั๊กเมนูของครู
- ข้อความในหน้า login
- หน้าลูกหนี้รายห้องและหน้าค้างชำระ เพราะเก็บตัวกรองไว้ใน URL อยู่แล้ว

## แนวทาง

| แนวทาง | ผล |
|---|---|
| **ตัวกรองอยู่ใน URL โดยใช้ฟังก์ชันรวม query string ฟังก์ชันเดียวที่ทุกหน้าใช้ร่วมกัน** ตรงกับแบบที่หน้าค้างชำระและหน้าลูกหนี้ใช้อยู่แล้ว | **เลือก** |
| เก็บตัวกรองไว้ใน sessionStorage | ไม่เลือก: แชร์ลิงก์ไม่ได้ และเพิ่มกลไกที่โปรเจกต์ยังไม่มี |
| ใช้ React context ร่วมกันข้ามหน้า | ไม่เลือก: รีเฟรชแล้วตัวกรองหาย |

## แบบที่อนุมัติ

- **ฟังก์ชันรวม query string:** `mergeQuery(current, next, defaults)` คืนค่า query string ใหม่
  - ค่าที่ว่างหรือเท่ากับค่าเริ่มต้นจะถูกลบออก
  - param อื่นที่มีอยู่แล้ว เช่น `year` และ `semester` เก็บไว้ตามเดิม
- **การเปลี่ยนตัวกรอง:**
  - dropdown และวันที่: ใช้ `router.push` ตามแบบเดิมของโปรเจกต์ กดย้อนกลับแล้วจะถอยไปทีละตัวกรอง
  - ช่องค้นหา: หน่วงเวลา 300 ms แล้วใช้ `router.replace` จะได้ไม่เพิ่มประวัติทีละตัวอักษร *(ผู้พัฒนาเลือก)*
- **ค่าในหน้ารายรับรายวันและส่วนลด:**
  - `from` และ `to` เป็น `YYYY-MM-DD` ค่าเริ่มต้นคือวันแรกของเดือนนี้ถึงวันนี้
  - ค่าที่ผิดรูปแบบให้ถอยกลับไปใช้ค่าเริ่มต้น
- **การเปลี่ยนภาคเรียน:** ในหน้ารายบุคคลให้ล้าง `grade` และ `classroom` เพราะห้องเป็นข้อมูลของแต่ละภาค
- **หน้ารายบุคคล:**
  - query key ประกอบด้วย ภาค ชั้น ห้อง และครูเท่านั้น
  - ผลลัพธ์ผ่าน `buildStudentRoster` ใน render
- **ลิงก์ไปหน้าใบแจ้งยอด:** แนบ query string ของหน้ารายชื่อไปด้วย
  - `basePath` ของหน้าใบแจ้งยอดเป็น `/reports/students/<id>`
  - ปุ่ม "กลับไปรายชื่อ" สร้าง URL `/reports/students?<query เดิม>`
- **แถบด้านข้าง:** ปรับ state ระหว่าง render ไม่ใช้ effect
  - เมื่อ `active` เปลี่ยนจาก false เป็น true ให้ตั้ง `open = true`
